cmloot — Forked, Extended, and Weaponized

h4ck3r@cmloot:~$

$ whoami

A fork of shelltrail/cmloot — the SCCM Content Library enumeration and extraction tool by Andreas Vikerup / Shelltrail.

$ diff upstream.md fork.md

The original cmloot does one thing well: it connects to an SCCM Distribution Point over SMB, traverses SCCMContentLib$, and downloads files by extension. Clean, effective, and no-frills.

This fork takes that foundation and turns it into a full offensive pipeline. Here is what changed:

$ cat additions.txt

[!] BFS Inventory with Progress

The original walked the share sequentially with no visibility. The fork uses BFS traversal with progress bars, ETA, and per-directory file counts so you know what is happening and how long to wait.

[!] Interactive Download Selection

Instead of blindly downloading everything matching an extension, the fork shows you a prioritized table (file size, category, priority markers) and lets you pick which files to grab. No more wasting time on 4 GB install.wim files when you only need boot.wim.

[!] Auto Pipeline

One flag — -auto — runs LDAP discovery, inventory, download, and classification in sequence. Point it at a DC and walk away.

[!] File Classification

Downloaded files are categorized offline: credentials, OSD media, config files, scripts, certificates, and more. High-value targets get [!] markers so you immediately see what matters.

[!] cmloot_analyze.py — Credential Deep Dive

A separate scanner that runs over downloaded loot and surfaces plaintext passwords, PSCredential usage, connection strings, private keys, API tokens, LDAP paths, service accounts — filtered, deduplicated, and rated by severity (CRITICAL / HIGH / MEDIUM). Supports JSON output for pipeline integration.

[!] ELEVATE-5: Distribution Point Takeover

The fork adds -elevate5 to extract Variables.dat from downloaded WIM boot images. Combined with PXEThief you can decrypt the embedded PKI certificate (Client Auth EKU, exportable private key) and authenticate as the DP machine account via Certipy. Full AD compromise from a single misconfigured DP.

[!] More Auth Options

Pass-the-hash (-hashes), computer account auth (-no-pass), Kerberos (-k), and NTLM relay via proxychains — all carried over from upstream, now with cleaner argument handling.

$ cat tl_dr.txt

Same SMB traversal core. New offensive surface. If you were using the original cmloot, the fork is a drop-in replacement that gives you targeting, classification, credential extraction, and ELEVATE-5 in a single tool.
